# AI-Based Outbound Sales System

This project predicts whether a customer should receive an outbound sales email using Machine Learning.

## Features
- Customer data processing
- ML model training
- Accuracy evaluation
- Email generation

## Technologies
- Python
- Pandas
- Scikit-learn

## How to Run

1. Install libraries:

pip install pandas scikit-learn

2. Train model:

python train_model.py

3. Run prediction:

python main.py
